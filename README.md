# MPMP – Constrained Growth

Repository ini berisi kode Python untuk mendukung analisis pemodelan pertumbuhan terbatas (*constrained growth*) pada kapasitas IT Data Center di Irlandia.

## Daftar Program

**1. `4_2_1_carrying_capacity.py`**

Program untuk memvisualisasikan kapasitas IT Data Center berdasarkan data historis dan nilai *carrying capacity* hasil estimasi model logistik.

**2. `4_2_2_perbandingan_eksponensial_logistik.py`**

Program untuk membandingkan pola pertumbuhan eksponensial dan logistik terhadap kapasitas IT Data Center di Irlandia.

## Konteks Penelitian

Pemodelan menggunakan data historis kapasitas IT Data Center di Irlandia periode 2019–2025. Parameter model logistik diperoleh melalui estimasi berdasarkan data historis.

Repository ini digunakan sebagai dokumentasi kode analisis dalam laporan mata kuliah MPMP.
